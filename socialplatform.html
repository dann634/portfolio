Social Platform

An online platform that allows users to create profiles, post updates, and interact with each other in a social media environment.

Project Overview

This is a project I undertook to better understand the mentality of creating a large scale social platform. Making sure the back end was secure, reliable and scalable were my biggest challenges, so I used a microservices architecture with an API gateway to direct traffic. The platform also uses token authentication with JWT tokens issued by a specialised service.

I used the Spring Boot framework for this project, in conjunction with Spring Security for auth and Spring JPA for data storage. For the front end I used JavaScript and HTML, which I hadn't used before, but after this project I am very comfortable using. I also use a PostgreSQL database to store user data securely and a Redis cache to increase the performance of user queries.
